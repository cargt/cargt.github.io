Tested Interfaces
------------------

Results for the 00414 (2 GB) on the 00365 carrier with ``cargt-image-dev``,
wrynose, October 2026.

.. list-table::
   :class: wrap-cells
   :header-rows: 1
   :widths: 25 75

   * - Interface
     - Result
   * - eMMC
     - Boots from eMMC. HS400ES, 200 MHz, 8-bit.
   * - microSD
     - Boots from microSD. Read/write with checksum verification, about
       19 MB/s write and 17 MB/s read. The 00365 limits the slot to 3.3 V
       high speed (50 MHz) for signal integrity.
   * - Ethernet ETH_A, ETH_B
     - 1 Gb/s link on both ports. ``iperf3``: 941 Mb/s each way and
       940 + 940 Mb/s bidirectional, 0 errors.
   * - CAN_A, CAN_B
     - Port-to-port loopback at 250 kbit/s, 500 kbit/s and 1 Mbit/s,
       20,000 frames each way, 0 lost. Note that ``can0`` is CAN_B and
       ``can1`` is CAN_A.
   * - USB-C (OSM USB_C)
     - Host, SuperSpeed (5 Gb/s) in both plug orientations, about 122 MB/s
       read from a USB 3 drive.
   * - Cameras
     - OS08A20 on CSI-1 and CSI-2, 1920×1080 through the NEO ISP; both
       cameras at once at about 29.5 fps each; 3840×2160 at 29.6 fps. CSI-2
       shares its PHY with the DSI display connector, so the two cannot be
       used together.
   * - Display
     - 10.1" LVDS (GLT1011280800IS1) with touch.

Checking USB-C SuperSpeed and plug orientation:

.. code-block:: bash

   lsusb -t                                   # device on bus 2 at 5000M
   cat /sys/class/typec/port1/orientation
   dd if=/dev/sda of=/dev/null bs=1M count=1024 iflag=direct

Streaming a camera full screen through the ISP:

.. code-block:: bash

   LIBCAMERA_PIPELINES_MATCH_LIST=nxp/neo gst-launch-1.0 libcamerasrc ! \
       video/x-raw,width=1920,height=1080 ! queue ! waylandsink fullscreen=true

Without ``LIBCAMERA_PIPELINES_MATCH_LIST=nxp/neo``, libcamera selects the
raw-only ISI pipeline instead of the ISP.
