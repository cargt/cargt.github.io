Source: every *.rootfs.manifest under yocto.cargt.com/images (scarthgap, wrynose, wrynose-rt), each board folder's BUILD-INFO.txt, and the deb feeds linux-imx/scarthgap, linux-imx/wrynose and openstlinux/scarthgap, read __MAPS_DATE__. Downloads and file dates are read __SCAN_DATE__. Initramfs manifests and the ST boot, user and vendor partition images are left out. wrynose-rt images are matched against the linux-imx/wrynose feed, because no RT feed is published. stm32mp25-cargt-00395-00365v3 has no image manifest.

Links come from each package's Depends and Recommends fields, resolved through Provides. "Top-level" means nothing else in the image depends on it. Packages that only depend on each other in a cycle count one member as top-level. "Kept in the image by" and "only in the image because of it" come from a dominator tree over all links. Kernel packages built for a different kernel than the feed's are matched to the same package in the feed with the kernel version swapped.

Installed sizes are measured from each image's published root filesystem: the total size of the files dpkg records for each package. Images without a published root filesystem (the container and Xen guest images) reuse the measurement of the same package build from another image. Packages that no image ships, and builds that were never measured, are estimated from the uncompressed size of the package's data archive, read from the end of the .deb; those sizes are marked "≈" and run slightly high for small packages.

The feed lookup covers each board's feed folders (all, its CPU tune, its SoC and the board itself). "Would be added" follows Depends and Recommends from the package, skipping anything the selected image already has or provides, and picks the first available choice where a dependency offers alternatives. Debug, source, documentation, test, static-library and translation packages are left out of the lookup.
